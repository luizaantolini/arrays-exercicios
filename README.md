# arrays-exercicios

## Projeto de exercícios com vetores em JavaScript

Este repositório contém exercícios para praticar o uso de vetores (arrays) em JavaScript sem recorrer a funções prontas de array.

# 💻 Atividades

## ex01 🔟
Ler 10 números inteiros e armazenar em um vetor. Em seguida, calcular e exibir a soma apenas dos números pares contidos no vetor.

## ex02 7️⃣
Preencher automaticamente um vetor numérico com 7 números gerados aleatoriamente e mostrar os valores gerados.

## ex03 🛰️
Solicitar ao usuário 10 números inteiros e armazenar em um vetor. Depois, solicitar um número e verificar quantas vezes ele aparece no vetor.

## ex04 🔟🛰️
Solicitar 10 números ao usuário e armazenar em um vetor. Depois, criar um novo vetor removendo os valores duplicados e exibir o vetor original e o vetor sem duplicatas.
